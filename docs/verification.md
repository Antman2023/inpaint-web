# 验证记录

## 2026-09-22

环境：Windows、Node.js v24.21.0，使用项目安装的 Playwright 浏览器及独立 Vite 测试服务。以下结果针对包含画笔采样、图片格式纠正和弹窗拖动修复的当前工作区。

### 完整浏览器回归

加入后述原图对比控件回归前，分别设置 `PLAYWRIGHT_BROWSER` 为 `chromium`、`firefox`、`webkit` 后执行 `npm run test:browser`：三个引擎均为 **23 项通过、0 项失败**，共 69 次测试执行。

- 合并指针采样与逐点事件的曲线预览像素一致；接口缺失、空采样列表、每帧光标更新及中断笔画清理通过。
- PNG/JPEG 元数据误标后的原图下载格式、扩展名及字节一致性通过；4097 像素宽的透明 PNG 缩小至 4096 后保留透明区域。
- 遮罩与弹窗内容之间的双向拖动不会关闭弹窗，正常点击遮罩及 Escape 关闭会恢复焦点；嵌套运行环境修复弹窗的失败重试通过。
- 导入失败、编辑器解码失败、Canvas 不可用、缓存读取超时、共享下载取消与重新加入、修图重试、布局变化、存储不可用及 Fast Refresh 行为全部通过现有回归。

`npm run check` 通过：158 项回归测试、源码与压缩模块各 6 项内存检查、代码检查、TypeScript 检查和生产构建。

### 原图对比控件补充

对比模式中禁用画笔大小调节，退出后恢复控件并保留原值。新增 `comparison.spec.cjs` 在 Chromium、Firefox 和 WebKit 中分别通过，覆盖 Home/End、方向键、鼠标拖动、裁剪比例、窗口缩放后保留位置、对比时不触发修复及退出后恢复涂抹。此改动后再次运行 `npm run check` 通过；此前的完整浏览器套件及真实模型结果不代表对此控件改动重新执行了全部测试。

### 后台预热与放大等待优化

修复模型预热改为共享会话准备，不再占用推理队列。新增单元测试验证下载未完成时其他模型可进入推理、取消预热等待后初始化仍阻止环境修复，以及完成后可正常修复环境。此改动后 `npm run check` 通过：159 项回归测试、两组各 6 项内存检查、代码检查和生产构建。

`warmup-priority.spec.cjs`、`cached-model.spec.cjs`、`inpaint-retry.spec.cjs` 在 Chromium、Firefox、WebKit 中共 9 次执行全部通过。测试让修复模型请求保持未完成，确认缓存放大生成 128 × 128 结果；随后补回修复模型响应，不增加编辑历史或弹出错误。运行库及模型字节为测试替身。

另设置 `MODEL_SMOKE_WARMUP=1`、`MODEL_SMOKE_REPAIR=0`，在 Chromium 153.0.8010.12 中执行真实模型检查，退出码为 0。并行发起修复预热和放大会话准备成功，随后取消恢复、64 × 64 修复及 256 × 256 放大通过，透明度检查分别为 4 和 7 个采样点。记录预热 38,360 ms、取消检查 17,323 ms、修复 4,836 ms、放大 61,469 ms；下载及初始化单独计入预热，不能与前表的取消耗时直接比较。此轮未重新运行完整环境重建检查。

### 修图下载进度反馈

修图等待模型时显示共享下载进度，未知总大小使用不确定进度；取消和完成会清除进度界面。`inpaint-progress.spec.cjs` 在三个浏览器中各两项通过，覆盖已知/未知长度、50% 进度恢复、取消后接续至 75%、单次下载和会话复用，以及只生成一次处理结果。Firefox 和 WebKit 的修图失败重试测试也通过。

此改动后 `npm run check` 再次通过（159 项回归、源码及压缩模块内存检查、代码检查和生产构建）。浏览器进度测试使用受控响应流及模拟推理，不测量真实下载速度，也未重新执行真实模型检查。

### 放大输出中的无效数值

先通过回归复现：模型返回非有限像素时，原实现未报错，而是把数值直接转换后返回图片。新增输出检查后，RGB 任一通道的 `NaN`、正无穷或负无穷均会终止处理；测试验证第二块出错后不再运行第三块，只报告已完成块的进度。有限值的正常裁剪、舍入及丢弃边缘填充保持原行为。

`upscale-output.spec.cjs` 在 Chromium、Firefox、WebKit 中通过：已有编辑结果保持原像素、缩略图及尺寸，不追加失败结果；随后重试复用原会话并成功追加结果。此处使用模拟推理注入错误，不是实际模型故障发生频率或性能测量。`npm run check` 通过（161 项回归、两组内存检查、代码检查及生产构建）。

### 示例图片超限响应提前退出

未压缩示例响应通过有效 `Content-Length` 声明超过 10 MB 时，在读取流前报错并取消响应。回归覆盖 `identity` 编码、恰好达到上限、压缩响应、异常大小声明，以及过小声明不能绕过实际读取限制。`npm run check` 通过（165 项回归、两组内存检查、代码检查及生产构建）。

新增 `example-size.spec.cjs` 在 Chromium、Firefox、WebKit 中通过：响应流读取次数为 0，取消已发起，即使取消确认仍未完成也能重试并加载真实本地示例图。Firefox 和 WebKit 的现有超限文件、解码失败后恢复测试亦通过。此测试用受控响应验证提前退出，不测量浏览器网络层已预取的字节数。

### 验证范围

浏览器套件拒绝外部网络请求，涉及推理的流程使用模拟运行库或故意失败的请求，未下载或执行真实模型。预期的模型预热失败和故障注入日志不代表本轮出现额外故障。

Playwright WebKit 不等同于真机 Safari。触摸指针捕获使用模拟事件，尚未验证真实触控笔、低内存设备、最大尺寸图片长时间处理和本轮改动下的真实模型画质。
